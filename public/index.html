2. Map, category & split names

Solo Easter Egg speedruns. BO2 uses IGT with RTA shown alongside it. BO3 uses RTA with IGT shown when available. The LiveSplit addon detects your game, map and category automatically when your split file identifies them. These choices set your optional therun.gg mapping.

In LiveSplit: use Black Ops II Zombies or Black Ops III Zombies as Game Name, or choose the matching game in the tracker component’s Game selector. For BO2 use Additional Info for your map, Bank/No Bank and Richtofen/Maxis route, and Easter Egg speedrun type. For BO3 use your map, gum category and Easter Egg speedrun type, or include your map and gum category in Category Name, for example Der Eisendrache - Mega Gums - Solo. Save your splits. You can also use a supported BO3 map as Game Name, such as Der Eisendrache, with Mega Gums as Category Name.

Black Ops II setup

Install the T6 timer/autosplitter and enable LiveSplit’s TCP server as required by T6. In Edit Splits, use Black Ops II Zombies as Game Name. Black Ops 2 Zombies, BO2 Zombies, BOII Zombies and Call of Duty variants are also recognized. You can instead choose Black Ops II Zombies in the Zombies Tracker component’s Game selector.

Include the map and route in Category Name or Additional Info. For example: TranZit - No Bank Richtofen - Solo. TranZit, Die Rise and Buried require Bank or No Bank, plus Richtofen or Maxis. For Mob of the Dead and BO2 Origins, use Mob of the Dead - Solo or Origins - Solo; their tracker category is Standard.

BO2 records and comparisons use IGT; RTA appears alongside it when LiveSplit supplies it. Let T6 initialize Game Time before running. Missing IGT pauses tracking instead of substituting RTA. BO2 splits use Fly 1–3 and End. Older Flight/Plane and final labels remain recognized; map custom names in Split aliases. BO2 Origins and BO3 Origins stay separate.

Solo · Easter Egg. BO2: IGT primary, RTA secondary. BO3: RTA primary. Zetsubou and Super Easter Egg exclude No Gums; Ascension and Shangri-La allow only Any%.

Super Easter Egg setup

Use one continuous LiveSplit file containing Shadows of Evil, The Giant, Der Eisendrache, Zetsubou No Shima, Gorod Krovi, and Revelations last. Name the category Super Easter Egg - Classic Gums - Solo, substituting your gum category. Choose Super Easter Egg in the addon’s Split aliases dropdown. 3. Choose a data source

Install your downloaded addon

Close LiveSplit, copy LiveSplit.ZombiesTracker.dll into its Components folder, then reopen it. Add Other → Zombies Tracker in Edit Layout and open its settings.

Paste your private runner key into the addon. Choose Automatic detection, Black Ops II Zombies, or Black Ops III Zombies under Game. Leave map/category on automatic, enable upload, click Apply, and save your layout. Set LiveSplit Game Name to the map, for example Der Eisendrache, and Category Name to No Gums, Classic Gums, Mega Gums, or Any%. Additional Info gum metadata is also read. When no category is provided, it defaults to Mega Gums (Any% on Ascension and Shangri-La). Alternatively, set Edit Splits → Game Name to Call of Duty: Black Ops III and include the map in Category Name, for example Der Eisendrache - Mega Gums - Solo. Correct unknown or conflicting map labels; a category override is available. Multiplayer labels block uploads.

LiveSplit uploads take priority automatically, even with therun.gg selected. After 30 seconds without addon updates, therun.gg resumes at a new run or reset so the same run is not recorded twice. Your saved therun.gg connection stays in place. Register on this server to obtain its runner key. If the addon interferes with your LiveSplit layout, remove it and use the optional therun.gg connection while compatibility is checked.

Enter the exact game/category labels displayed on therun.gg. Source labels are matched before recording anything. Your tracker username is separate from the source username; this connection does not verify ownership.

Collects splits observed from now on; does not import lifetime history. Update delays and pause detection depend on the upstream feed.

Commands and cooldowns

In your connected Twitch or YouTube chat, these commands use your linked runner. To check someone else, add their tracker name: !current Penguine or !current @Penguine. On this website, include a runner name for runner stats. Use @name if the name matches a map name.

CommandWhat it shows
!currentCurrent run and split
!sessionCurrent or last session summary
!sessionpbFastest completed run this session
!best split alltimeAll-time best split and segment
!best split sessionBest split and segment this session
!splits alltimeSplit bests; use session for this session
!paceAhead or behind your PB at the latest split; WR comparison when available
!pb mapYour PB for a map
!wr mapSolo WR for a map
!helpList available commands

Replace map with a map name (for example, DE) and split with a split name (for example, Rocket).

Choose a category: map-specific PB and WR commands default to Mega Gums. Add another category when needed: !pb DE Classic Gums or !wr DE Any%. WR commands use a map, not a runner.

Detected or selected map: omit the map to use the runner’s detected map/category. Add a map and optional category after the other arguments: !best Penguine Rocket alltime DE Classic Gums, !splits Penguine session DE, or !sessionpb Penguine DE. Explicit BO3 maps default to Mega Gums. !current and !pace require a matching current run; they do not invent live stats for another map. !wr alone uses the linked chat runner’s detected profile.

Cooldowns

The default is 15 seconds between command replies. Change it to 5–300 seconds in your channel settings above. Each connected channel has its own cooldown. Announcements wait at least 15 seconds so accidental splits can be undone; platform limits still apply.

Where the stats come from

World records come from Zombies World Records (ZWR), matched by Solo map and gum category. Cached records may lag behind updates. Achieved dates use the ZWR record-added date when the run date is unavailable.

Split matching uses the LittleMontyBot guide: known names first, then conservative timing hints for Mega Gums/Any%. Optional and alternative splits are supported. Ambiguous names stay unchanged; Moon and Origins do not use timing-only matching. Compatible BO3 autosplitter selections supply split hints when their layout matches. LiveSplit names, records, and layouts are preserved. ZNS uses Rainbow Round End; KT4 is separate.

Bring runner alerts to your server

Add the bot, then choose where it posts and which role it pings. Each server has its own alerts.

  1. Use Add bot to a server below and approve on Discord. You need Manage Server permission. The bot may appear offline in Discord; slash commands and alerts can still work.
  2. In Server Settings → Roles, create a role for each map you want pings for, such as SOE Alerts, DE Alerts, or Origins Alerts. Enable Allow anyone to @mention this role and give it to members who want those pings. Roles are optional if you only want messages.
  3. Choose your alerts channel, for example #run-alerts. Give the bot View Channel and Send Messages there. All maps can share one channel, or you can use separate channels.
  4. Sign in here with your runner key, then Connect Discord. Choose the server, destination channel, map role and alert details below. Save once for each split/category you want.

Set up alerts with Discord commands

Run /track-alert inside the channel that should receive the alerts. You can create every map's alerts in that one channel. For another destination, run the command in that channel instead.

Example: ping @SOE Alerts when any public runner reaches Sword in 8:10 or faster on Shadows of Evil:

/track-alert player:* split:Sword role:@SOE Alerts mode:At or under a time threshold:8:10 map:Shadows of Evil

Choose the role, mode and map from Discord's option menus. player:* means all public runners and requires a map; use a tracker name for one runner. For this example, the category defaults to Mega Gums. Select another allowed category explicitly when needed.

Leave mode empty for every split completion. Choose At or under a time and enter a threshold for fast splits only, or Ahead of WR split when a matching WR split is available. Each rule covers one split, map, category and channel; repeat for extra alerts. You only need to set each rule once.

/track-alerts lists this server's alerts and IDs. /track-unalert id:<ID> removes one. These settings are shared with the website. Setup replies are only visible to you.

Use recognized split names such as Sword, Rocket and Rainbow Round End. Match the runner's saved alias for custom or Super Easter Egg splits. A non-standard split warning means you should check the name.

Missing alerts or pings?
  • Command missing: use the invite button again and check Manage Server permission.
  • Channel missing or nothing posts: check channel permissions for you and the bot, and that the runner's map/category matches the rule.
  • Message posts without a ping: make the role mentionable and give it to the members who want alerts.
  • Every run pings: remove the rule and recreate it, selecting the time mode from Discord's menu and adding a threshold.

Alerts track public, non-practice live runs. Resets or undone splits can cancel pending alerts. After inviting the bot, refresh the server list here.
