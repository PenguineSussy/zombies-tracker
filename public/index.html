GET CONNECTED

Your runner setup

Not signed in

1. Create your tracker identity

Choose a public username. Your private runner key controls your account; save it somewhere secure. Platform identity verification is not part of this alpha.

Save this private runner key. It is only shown when created or rotated.

Sign-in is kept in this browser tab's session only. The downloaded companion configuration also contains your key.

2. Define the run

Use identical category details for comparable runs. Names here are community-defined, not verified leaderboard categories.

Match your split names to shared milestones. Repeated milestones need distinct names.

3. Choose a data source

Enable LiveSplit's TCP server on port 16834. Download the configuration into the project's companion folder as config.json, then run npm run companion.

Enter the exact game/category labels displayed on therun.gg. Source labels are matched before recording anything. Your tracker username is separate from the source username; this connection does not verify ownership.

Collects checkpoints observed from now on; does not import lifetime history. Update delays and pause detection depend on the upstream feed.

Connect the bot accounts

The operator configures platform credentials in .env. See SETUP.md in the project for application setup and command registration. Credentials never belong in a public chat.

Configuration badges indicate settings are present; they do not confirm platform authorization. This local alpha has no one-click public OAuth onboarding yet.

Add a WR checkpoint benchmark

Operator-only. Uses the map/category selected in Runner setup. Enter cumulative checkpoint milliseconds and a source URL. No fabricated world records are bundled.

New attempts use the latest matching benchmark. Existing attempts keep their original comparison.
